## 핵심 정리
**순전파**: 층마다 `z = a·W + b` → ReLU, 마지막은 sigmoid로 구매 확률 p

**역전파** (연쇄법칙을 뒤에서 앞으로):
1. 출력층 오차 `dz = w·(p − y) / N` — sigmoid와 이진 교차 엔트로피를 같이 미분하면 '예측 − 정답'만 남음. `w`는 클래스 가중치라 구매 샘플의 오차가 3.2배로 크게 전달됨
2. 가중치 기울기 `dW = (이 층의 입력)ᵀ · dz`, `db = dz의 합`
3. 앞 층으로 전달 `da = dz · Wᵀ` — 연결된 가중치만큼 책임을 나눠 돌려줌
4. 드롭아웃 — 순전파 때 꺼진 노드는 기울기도 0
5. ReLU — `z ≤ 0`이던 노드는 기울기 0 (꺼진 노드는 책임 없음)
6. 2로 돌아가 첫 층까지 반복

**Adam**: 기울기 평균(m, 방향)과 기울기 제곱 평균(v, 크기)을 기억해 가중치마다 보폭을 맞춤. `W -= α · m / (√v + ε)`, α = 학습률 · √(1−β₂ᵗ) / (1−β₁ᵗ)

## 확인한 결과 (2026-11-05)
- study01: 역전파 기울기와 수치 미분 차이 1e-10 수준
- study02: 4개 층 모두 검산 통과 (상대 오차 1e-8 이하), 가중치 수 14,281개로 Keras와 같음. 시드 42로 최고 검증 PR-AUC 0.706 (Keras 최종 모델 0.7053 ± 0.0039와 같은 수준. 난수 방식이 달라 똑같지는 않음)
- study03: Keras와 손실 차이 1e-8, 기울기 차이 1e-7, Adam 한 걸음 뒤 가중치 차이 1e-7 → `model.fit()`이 하는 일과 같음
- 알게 된 점: Keras Adam은 ε을 보정 전 √v에 더함. 교과서 식(`m̂ / (√v̂ + ε)`)으로 짜면 기울기가 거의 0인 가중치(꺼진 ReLU에 연결된 것)에서 첫 걸음이 최대 2e-3 달라졌음
