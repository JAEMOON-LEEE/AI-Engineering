검증 세트(validation_final) 기준, 시드 42/43/44 평균±표준편차. test는 사용하지 않음.

## 초기값 출처
- hidden: (28, 56, 28) (논문 3.7절)
- dropout: 0.0 (논문·교재에 값 없음)
- optimizer: SGD (논문 3.7절)
- lr: 5e-05 (논문 3.7절)
- imbalance: none (논문 Table 5)

## 단계별 흐름
- **0 출발점** (논문+교재 초기값: (28,56,28), SGD 5e-05, 배치 128, 최대 30에폭, 조기종료 없음, 불균형 처리 없음): 검증 PR-AUC 0.2615, 재현율 0.031, 양성 예측 비율 0.007 (실제 구매율 0.156)
- **1 불균형**: 증상 [재현율 0.031, 양성 예측 0.007 vs 실제 0.156] → 가설: 소수 클래스(구매)를 무시하도록 학습됨 → 후보 3개 비교 → **클래스 가중치** 선택 (검증 PR-AUC 0.3432±0.0742, 재현율 0.672)
- **2 느린 학습**: 증상 [최고 에폭 30/30 (마지막까지 개선 중: True)] → 가설: 학습률이 작거나 옵티마이저가 느려 정해진 에폭 안에 수렴하지 못함 → 후보 16개 비교 → **Adam 0.01** 선택 (검증 PR-AUC 0.6907±0.0097, 재현율 0.812)
  - 옵티마이저는 Adam로 고정: 적응형 옵티마이저끼리는 차이가 표준편차보다 작아 무승부로 보고, 교재 5.4 [보충] 권고(특별한 이유가 없으면 Adam)를 따름. 학습률은 Adam 후보 중 1위
- **3 에폭·조기종료**: 증상 [최고 에폭 12/30, 최저점 대비 마지막 검증 손실 +22%] → 가설: 최고점 이후 과잉 적합 → 후보 3개 비교 → **최대 30에폭, 조기종료 없음** 선택 (검증 PR-AUC 0.6907±0.0097, 재현율 0.812)
- **4 모델 크기**: 증상 [학습 PR 0.784 - 검증 PR 0.691 = +0.093] → 가설: 모델이 학습 데이터에 비해 커서 과잉 적합 → 후보 5개 비교 → **현재 구조 + 드롭아웃 0.2** 선택 (검증 PR-AUC 0.6919±0.0099, 재현율 0.813)
- **5 배치 크기 확인**: 증상 [확인 단계(증상 판정 아님), 현재 시드 간 표준편차 0.0099] → 가설: 교재 범위(32~256, 4.5.2)에서 비교해 1위 선택 → 후보 4개 비교 → **배치 64** 선택 (검증 PR-AUC 0.6945±0.0074, 재현율 0.805)
- **6 학습률 재확인**: 증상 [단계 순서 편향 확인(증상 판정 아님)] → 가설: 앞 단계에서 다른 조건일 때 고른 학습률이 최종 조건에서도 맞는지 → 후보 3개 비교 → **학습률 0.00333333** 선택 (검증 PR-AUC 0.6961±0.0050, 재현율 0.812)
- **7 구조 넓게 확인**: 1~3층 × 32/64/128 노드 9개 + 현재 구조 비교 → 1위 3층×128 (128, 128, 128) (차이 +0.0018)가 표준편차(0.0085) 이내라 무승부 -> 현재 구조 유지
- **8 에폭 재확인**: 최종 조건에서 최대 30, 50, 100에폭 비교 → 1위 최대 100에폭 (차이 +0.0088)가 표준편차(0.0139) 이내라 무승부 -> 최대 30에폭 유지
