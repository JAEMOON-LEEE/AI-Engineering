# C1 3주차 재검증 요약

실험 목적: 2주차 상위 설정과 C2 드롭아웃 결과를 시드 5개로 재검증한다.

로그 번호: C1-080 ~ C1-154

## 조건

공통: 공식 분할(`data/final` train_clean / validation_final, test 미사용), 입력 26차원, 배치 32, 최대 50에폭, 조기종료 `val_pr_auc` / max / patience 5 / `restore_best_weights=True`, class_weight balanced, 임계값 0.5.

후보 5개 × dropout `{0, 0.2, 0.3}` × 시드 `{42, 43, 44, 45, 46}` = 75회.
