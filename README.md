# AI-Engineering 조별 프로젝트

> 최종 업데이트: 2026-10-13 (C1 작성). 다른 파트 진행 상황은 각자 확인 후 고쳐 주세요.

## 프로젝트 개요
- **주제**: 온라인 쇼핑 구매 의도 예측 (UCI Online Shoppers Purchasing Intention Dataset)
- **목적**: 세션 행동 데이터로 구매 가능성을 예측해, 가능성 높은 방문자에게는 프로모션을 집중하고 이탈 가능 고객에는 대응
- **데이터**: 12,330 세션, 18개 컬럼, 구매 비율 약 15.5%(클래스 불균형), 결측치 없음, CC BY 4.0
- **메인 모델**: MLP (Keras)
- **비교 기준선**: 로지스틱 회귀, 랜덤포레스트 (B)
- **주 지표**: PR-AUC (모델 선택 기준), Recall·F1 보조 (임계값 0.5 기준)
  - Accuracy는 쓰지 않음: 구매가 15.5%뿐이라 전부 "구매 안 함"으로 찍어도 84%가 나옴
- **일정**: 9/21~10/19 (4주 + 예비일), **최종 모델 동결 10/14**, 발표 10/20주~

## 알려진 이슈 / 팀 확인 필요 사항
1. **최종 모델 동결 대기 (10/14)**: C2가 C1 최종 조건 위에서 정규화 실험을 다시 돌려 드롭아웃·클래스 가중치를 확정해야 함 (`members/C2/c2_final_experiment.py` 예정). `--smoke`로 C1 결과(0.6961)와 일치하는지 먼저 확인.
2. **기준선이 MLP보다 높음**: 검증 PR-AUC 랜덤포레스트 0.728 > MLP 0.696. 발표에서 반드시 질문 나올 부분이라 해석을 팀에서 맞춰야 함 (B·C1·C2). 참고: 선행 연구(Tanvir 2023)도 이 데이터에서 트리 계열이 MLP보다 높았음.
3. **시연 입력 1건 전처리 주의 (A)**: `common_preprocess.py`는 val·test에도 `drop_first=True`를 씀. 데이터가 여러 건일 땐 괜찮지만, 시연처럼 **세션 1건만 넣으면 Month·VisitorType 열이 잘못 만들어짐** (오류 없이 확률만 틀림). 시연 입력은 `drop_first=False`로 원핫 → 학습 때 저장한 열 목록으로 맞춤 → 학습 때 저장한 scaler로 변환.
4. **테스트 세트 평가 담당·시점 미정**: 동결 후 1회만. B `run_baseline.py --evaluate-test`와 MLP를 같은 시점에 평가하는 방안 검토.
5. **임계값 미확정 (B)**: 현재 0.5 기준. 비용 기준 합의 후 확정.
6. **예측 결과 공유 (C1·C2 → B)**: B 요청 형식 `row_id,split,y_true,y_probability,model_name` (validation, 최종 모델 기준).
7. **사용하지 않는 예전 코드**: `members/C2/c2_experiments.py`(train 재분할, 시드 [42,1,2]), 예전 `c2_regularization_experiment.py`의 `--smoke`(C1 파일 이동으로 동작 안 함) → 발표 수치에 쓰지 않음.
