# AI-Engineering 조별 프로젝트

> 최종 업데이트: 2026-11-05 (C1 작성). MLP 튜닝을 처음부터 다시 정리하고 최종 모델을 새로 동결함. 다른 파트 진행 상황은 각자 확인 후 고쳐 주세요.

## 프로젝트 개요
- **주제**: MLP 모델 · 온라인 쇼핑몰 구매 의도 예측 (UCI Online Shoppers Purchasing Intention Dataset)
- **목적**: 세션 행동 데이터로 구매 가능성을 예측해, 가능성 높은 방문자에게는 프로모션을 집중하고 이탈 가능 고객에는 대응
- **데이터**: 12,330 세션, 18개 컬럼, 구매 비율 약 15.5%(클래스 불균형), 결측치 없음, CC BY 4.0
- **메인 모델**: MLP (Keras)
- **비교 기준선**: 로지스틱 회귀, 랜덤포레스트 (B)
- **주 지표**: PR-AUC (모델 선택 기준), Recall·F1 보조
  - Accuracy는 쓰지 않음: 구매가 15.5%뿐이라 전부 "구매 안 함"으로 찍어도 84%가 나옴

## MLP 튜닝 과정 (11/5 다시 정리, 검증 세트 기준)
값을 고르는 모든 단계는 **"검증 PR-AUC 3시드 평균 1위"** 규칙으로 통일. 평가는 검증 PR-AUC가 가장 높은 에폭의 가중치로 되돌린 뒤 sklearn PR-AUC로 보고.

| 단계 | 내용 | 결정 | 검증 PR-AUC |
|---|---|---|---|
| 0 | 초기값 (논문 28-56-28 + 교재, SGD+NAG 0.00005, 배치 128, 30에폭, 클래스 가중치) | 출발점 | 0.343 |
| 1 | 에폭 300으로 늘려 확인 | 300에폭에도 계속 오름 → 학습률 문제 | (확인만) |
| 2 | SGD 학습률 4개 비교 | 0.1 ≈ 0.01 | 0.678 |
| 3 | 옵티마이저(SGD·RMSprop·Adam) × 학습률 | **Adam 0.01** | 0.691 |
| 4 | 과적합 확인 (최고 에폭 12/30, 이후 학습↑ 검증↓) | 과적합 판정 | – |
| 5 (C2) | 드롭아웃 0/0.1/0.2/0.3/0.5, 조기종료 참고 | **드롭아웃 0.2**, 조기종료 미채택 | 0.692 |
| 6 | 배치 32/64/128/256 | **64** | 0.6945 |
| 7 | 구조 9개 (1~3층 × 폭 ×0.5/×1/×2) | **56-112-56** | 0.7016 |
| 8 | 학습률 재확인 (0.01의 ÷3 / 그대로 / ×3) | **0.01/3** | **0.7053 ± 0.0039** |
| 9 | 최대 에폭 30/50/100 | **30 유지** (늘려도 같음) | 0.7053 |
| 10 | 시드 42로 최종 모델 동결 | 동결 | 0.7018 |

### 최종 모델 설정
| 항목 | 값 |
|---|---|
| 은닉층 | 56-112-56, ReLU, he_normal (가중치 14,281개) |
| 출력·손실 | sigmoid, 이진 교차 엔트로피 |
| 옵티마이저·학습률 | Adam, **0.01/3** (코드에는 `0.01/3` 그대로, `0.0033`으로 넣으면 결과가 달라짐) |
| 배치 · 에폭 | 64 · 최대 30, 검증 PR-AUC 최고 에폭 가중치 사용 |
| 정규화 | 드롭아웃 0.2 (모든 은닉층), 조기종료 없음 |
| 불균형 처리 | 클래스 가중치 balanced (구매 3.20 / 미구매 0.59) |

- **검증 PR-AUC 0.7053 ± 0.0039** (시드 42/43/44 = 0.7018 / 0.7094 / 0.7047)
- 동결 모델(시드 42): 검증 PR-AUC 0.7018, 재현율 0.848, 정밀도 0.459, F1 0.596 (임계값 0.5 기준, 참고용)
- 시드 42는 실험 시작 전에 정한 고정 시드. 세 시드 차이가 흔들림 범위 안이라 성능이 가장 높은 시드를 따로 고르지 않음

## 알려진 이슈 / 팀 확인 필요 사항
1. **임계값 다시 정해야 함 (B)**: 모델이 바뀌어 예전 임계값(0.66)은 쓸 수 없음. 새 `validation_predictions_mlp.csv`로 검증 세트에서 다시 정함 (테스트 결과로 고르지 않기).
2. **테스트 평가 전 예전 결과 파일 옮기기 (B)**: `run_frozen_mlp_test.py`는 `results/B/metrics/final_test_mlp_metrics.csv`나 `results/B/predictions/final_test_mlp_predictions.csv`가 이미 있으면 멈춤. 예전 모델 결과를 다른 곳으로 옮긴 뒤 `--threshold`를 넣어 1회 실행.
3. **기준선이 MLP보다 높음**: 검증 PR-AUC 랜덤포레스트 0.728 > MLP 0.705. 발표에서 질문 나올 부분이라 해석을 팀에서 맞춰야 함. 참고: 선행 연구(Tanvir 2023)도 이 데이터에서 트리 계열이 MLP보다 높았음.
4. **시연 입력 (A)**: 세션 1건만 넣을 땐 `predict_mlp.predict_session()`을 쓸 것 (원핫 열 문제 처리됨). 모델 폴더 경로는 그대로 `members/C1/final_model`.
5. **예측 확률 해석**: 클래스 가중치로 학습해 확률이 실제 구매 확률보다 높게 나옴 → 순위 판단용 점수로 해석.
