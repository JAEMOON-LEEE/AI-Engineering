# AI-Engineering 조별 프로젝트

> 최종 업데이트: 2026-11-08. 최종 MLP, 임계값 0.75, validation·test 평가 결과를 반영함.

## 프로젝트 개요
- **주제**: MLP 모델 · 온라인 쇼핑몰 구매 의도 예측 (UCI Online Shoppers Purchasing Intention Dataset)
- **목적**: 세션 행동 데이터로 구매 가능성을 예측해, 가능성 높은 방문자에게는 프로모션을 집중하고 이탈 가능 고객에는 대응
- **데이터**: 12,330 세션, 18개 컬럼, 구매 비율 약 15.5%(클래스 불균형), 결측치 없음, CC BY 4.0
- **메인 모델**: MLP (Keras)
- **비교 기준선**: 로지스틱 회귀, 랜덤포레스트 (B)
- **주 지표**: PR-AUC (모델 선택 기준), Recall·F1 보조
  - Accuracy는 쓰지 않음: 구매가 15.5%뿐이라 전부 "구매 안 함"으로 찍어도 84%가 나옴

## MLP 튜닝 과정 (11/5 다시 정리, 검증 세트 기준)
값을 고르는 모든 단계는 **"검증 PR-AUC 3시드 평균 1위"** 규칙으로 통일. 평가는 검증 PR-AUC가 가장 높은 에폭의 가중치로 되돌린 뒤 sklearn PR-AUC로 보고.

| 단계 | 내용 | 결정 | 검증 PR-AUC |
|---|---|---|---|
| 0 | 초기값 (논문 28-56-28 + 교재, SGD+NAG 0.00005, 배치 128, 30에폭, 클래스 가중치) | 출발점 | 0.343 |
| 1 | 에폭 300으로 늘려 확인 | 300에폭에도 계속 오름 → 학습률 문제 | (확인만) |
| 2 | SGD 학습률 4개 비교 | 0.1 ≈ 0.01 | 0.678 |
| 3 | 옵티마이저(SGD·RMSprop·Adam) × 학습률 | **Adam 0.01** | 0.691 |
| 4 | 과적합 확인 (최고 에폭 12/30, 이후 학습↑ 검증↓) | 과적합 판정 | – |
| 5 (C2) | 드롭아웃 0/0.1/0.2/0.3/0.5, 조기종료 참고 | **드롭아웃 0.2**, 조기종료 미채택 | 0.692 |
| 6 | 배치 32/64/128/256 | **64** | 0.6945 |
| 7 | 구조 9개 (1~3층 × 폭 ×0.5/×1/×2) | **56-112-56** | 0.7016 |
| 8 | 학습률 재확인 (0.01의 ÷3 / 그대로 / ×3) | **0.01/3** | **0.7053 ± 0.0039** |
| 9 | 최대 에폭 30/50/100 | **30 유지** (늘려도 같음) | 0.7053 |
| 10 | 시드 42로 최종 모델 동결 | 동결 | 0.7018 |

### B 최종 평가 (`members/B/README_B.md`)

| 대상 | 임계값 | Precision | Recall | F1 | AP |
|---|---:|---:|---:|---:|---:|
| 로지스틱 회귀 validation | 0.50 | 0.504 | 0.723 | 0.594 | 0.601 |
| 랜덤포레스트 validation | 0.50 | 0.647 | 0.634 | 0.640 | 0.728 |
| 최종 MLP validation | 0.50 | 0.459 | 0.848 | 0.596 | 0.702 |
| 최종 MLP test | **0.75** | **0.676** | **0.649** | **0.662** | **0.729** |

- 최종 임계값 0.75는 validation F1 최대 기준으로 test 확인 전에 확정했다.
- validation에서 랜덤포레스트의 AP와 F1이 MLP보다 높고, MLP의 Recall이 더 높다.
- test에서는 최종 MLP만 평가했으므로 기준선과 test 성능을 직접 비교하지 않는다.

## 해석 시 주의 사항

1. **랜덤포레스트와 MLP**: validation AP는 랜덤포레스트 0.728, 최종 seed 42 MLP 0.702이다. MLP가 모든 지표에서 우수하다고 표현하지 않는다.
2. **임계값 0.75**: 실제 비용 자료가 없어 사업상 최적값이라고 할 수 없다. 이번 validation에서 F1이 가장 높았던 값이다.
3. **예측 점수**: 클래스 가중치로 학습해 보정된 실제 구매 확률로 해석하지 않고 순위·분류용 점수로 사용한다.
4. **시드 평균과 단일 모델**: 튜닝 결과 0.7053은 3시드 평균 AP이고, 최종 seed 42 모델의 validation AP는 0.7018이다.
5. **시연 입력**: 세션 1건은 `predict_mlp.predict_session()`으로 처리한다.
