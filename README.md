# AI-Engineering 조별 프로젝트

## 프로젝트 개요
- **주제**: 온라인 쇼핑 구매 의도 예측 (UCI Online Shoppers Purchasing Intention Dataset)
- **목적**: 세션 행동 데이터로 구매 가능성을 예측해, 가능성 높은 방문자에게는 프로모션을 집중하고 이탈 가능 고객에는 대응
- **데이터**: 12,330 세션, 18개 컬럼, 구매 비율 15.5%(클래스 불균형), 결측치 없음, CC BY 4.0
- **메인 모델**: MLP (신경망)
- **비교 기준선(baseline)**: 로지스틱 회귀, 랜덤포레스트
- **평가 지표**: Recall, F1, PR-AUC 중심 (Accuracy는 사용 안 함 — 구매 15.5%뿐이라 전부 "구매 안 함"으로 찍어도 84% 나오는 착시 있음)
- **일정**: 9/21~10/19 (4주 + 예비일), 발표는 10/20주차~

## 팀 구성 및 역할
- **A**: 데이터 분할(train/test), 공통 전처리
- **B**: 평가 스크립트 (Recall/F1/PR-AUC 계산, 혼동행렬)
- **C1**: MLP 구조, 옵티마이저·학습률·배치 크기 튜닝
- **C2**: 드롭아웃·조기종료(정규화) 튜닝

## 폴더 구조
- `data/` : 원본 및 공통 train/test 데이터
- `common/` : 팀 전체가 같이 쓰는 "확정" 코드 (분할, 전처리, 평가) — 확정 후 변경 금지
- `members/` : 각자(A/B/C1/C2) 실험 공간
- `results/` : 실험 로그, 학습곡선 등 결과물
- `docs/` : 발표 자료

## 알려진 이슈 / 팀 확인 필요 사항
1. **검증(validation) 세트 미확정**: A가 제공한 건 train/test 80:20 분할뿐이고 val 분할이 없음. 현재 C1은 train을 다시 train/val로 임시 분할해서 사용 중. B의 평가 스크립트가 오면 공식 val 분할 기준으로 교체 필요.
2. **공통 전처리 미확정**: 현재 C1은 임시 전처리(Weekend int 변환, Month/VisitorType 원-핫)로 진행 중. A의 공통 전처리 스크립트 나오면 교체 필요.
3. **과적합 관찰됨**: MLP baseline에서 val_loss가 epoch 6~7 이후 상승 시작 (train은 계속 개선되지만 val은 악화). 최대 에폭·조기종료 조건을 C2와 미리 맞춰야 구조/옵티마이저 비교가 공정해짐.
